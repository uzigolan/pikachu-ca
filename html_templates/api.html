Get Private Key by Name 
curl -k \
  -H "Authorization: Bearer <API_TOKEN>" \
  https://{{ server_dns_name }}/api/keys/my-key/private
curl --cert client.crt --key client.key \
  -H "Authorization: Bearer <API_TOKEN>" \
  https://{{ server_dns_name }}:{{ trusted_https_port }}/api/keys/my-key/private
 Enterprise only. Returns private key PEM for the named key. Requires API token. Works on normal HTTPS and on TRUSTED_HTTPS mTLS. User token sees own keys only; admin token may access any key.

Pre-Shared Key
Enterprise only		 Create Pre-Shared Key 
curl -k -X POST \
  -H "Authorization: Bearer <API_TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{"name":"device-001","purpose":"mqtt-bootstrap","validity":"30d","length":48,"rotation_interval":"2m"}' \
  https://{{ server_dns_name }}/api/preshared_keys
 Enterprise only. Creates a named PSK for the token owner and returns the secret once. Optional fields: purpose, validity, length, rotation_interval.
Get Pre-Shared Key by Name 
curl -k \
  -H "Authorization: Bearer <API_TOKEN>" \
  https://{{ server_dns_name }}/api/preshared_keys/device-001
curl --cert client.crt --key client.key \
  -H "Authorization: Bearer <API_TOKEN>" \
          https://{{ server_dns_name }}:{{ trusted_https_port }}/api/preshared_keys/device-001
 Enterprise only. Returns the secret for the named PSK as a downloadable text response. Requires API token. Works on normal HTTPS and on TRUSTED_HTTPS mTLS. User token sees own PSKs only; admin token may need ?user_id= or ?username= if the name is not unique system-wide.
Delete Pre-Shared Key by Name 
curl -k -X DELETE \
  -H "Authorization: Bearer <API_TOKEN>" \
  https://{{ server_dns_name }}/api/preshared_keys/device-001
curl --cert client.crt --key client.key -X DELETE \
  -H "Authorization: Bearer <API_TOKEN>" \
  https://{{ server_dns_name }}:{{ trusted_https_port }}/api/preshared_keys/device-001
 Enterprise only. Deletes the named PSK. Works for active, revoked, or expired PSKs. Returns JSON with deleted=true, id, name, and user_id. Requires API token. Admin token may need ?user_id= or ?username= if the name is not unique system-wide.
Rotate Pre-Shared Key by Name 
curl -k -X POST \
  -H "Authorization: Bearer <API_TOKEN>" \
  https://{{ server_dns_name }}/api/preshared_keys/device-001/rotation/start
curl --cert client.crt --key client.key -X POST \
  -H "Authorization: Bearer <API_TOKEN>" \
  https://{{ server_dns_name }}:{{ trusted_https_port }}/api/preshared_keys/device-001/rotation/start
 Enterprise only. Rotates the PSK value immediately and switches it into rotating mode. Returns JSON including the new value, rotation_mode, rotation_interval, last_rotated_at, and next_rotation_at. Requires API token. Admin token may need ?user_id= or ?username= if the name is not unique system-wide.
Stop Rotating Pre-Shared Key by Name 
curl -k -X POST \
  -H "Authorization: Bearer <API_TOKEN>" \

 Enterprise only. Stops rotating mode for the named PSK and clears the next scheduled rotation. Returns JSON including rotation_mode, rotation_interval, last_rotated_at, and next_rotation_at. Requires API token. Admin token may need ?user_id= or ?username= if the name is not unique system-wide.
SCEP
Enterprise only		 SCEP GetCaps 
sscep getcaps -u http://{{ server_dns_name }}:{{ scep_http_port }}/scep
curl http://{{ server_dns_name }}:{{ scep_http_port }}/scep?operation=GetCACaps
 Query server capabilities (AES, DES3, POSTPKIOperation, SHA-256, etc.)
SCEP GetCA 
sscep getca \
  -u http://{{ server_dns_name }}:{{ scep_http_port }}/scep \
  -c ca.crt
 Download CA certificate (prerequisite: RSA-based SubCA)
SCEP Enrollment 
sscep enroll \
  -u http://{{ server_dns_name }}:{{ scep_http_port }}/scep \
  -k client.key \
  -r client.csr \
  -c ca.crt \
  -l client.crt \
  -E aes \
  -S sha256
 Enroll certificate via SCEP. Options: -E (encryption: aes|3des), -S (signature: sha256|sha512)
Challenge Password (API Token) 
curl -X POST \
  -H "Authorization: Bearer <API_TOKEN>" \
  http://{{ server_dns_name }}:{{ http_port }}/api/challenge_passwords
 Generates a challenge password tied to the token's user. Response: value, expires_at, validity, user_id.
EST
Enterprise only		 EST Enrollment 
curl -k -X POST \
  --data-binary @etx.csr.der \
  https://{{ server_dns_name }}/.well-known/est/simpleenroll \
  -H "Content-Type: application/pkcs10" \
  --output etx.crt.p7
estclient enroll \
  -server {{ server_dns_name }} \
  -insecure \
  -csr etx.csr \
  -out etx.crt
 Using curl accepts DER CSR and returns signed cert in PKCS#7
