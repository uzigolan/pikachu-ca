MCP
AI Agent Integration

Connect your AI assistant (GitHub Copilot, Claude, etc.) directly to {{ product_name }} using the pki-mcp Model Context Protocol server. The AI can then issue certificates, manage keys, query events, and more — all through natural language.

What can I ask?

Trigger words: pika, pikachu — or just ask directly about the PKI server, certificates, or any CA operation.

  • Certificate lifecycle: "pika, list the certificates signed in July 2026" or "show all expired certificates on the CA".
  • Issue a certificate: "pikachu, generate an EC key and sign a new certificate for device-001 using the default RA policy".
  • Keys: "pika, list all EC keys" or "pikachu, generate a new RSA-2048 key named vpn-gw".
  • Enrollment protocols: "create a SCEP challenge password valid for 30 minutes" or "pikachu, show the EST CA chain".
  • Revocation & OCSP: "pika, revoke certificate ID 42" or "check the OCSP status of serial 0xb4c995dd43eaee59".
  • Audit & events: "pikachu, show all revoke events from last week" or "pika, who signed certificates yesterday?"
  • PSKs: "list all pre-shared keys and their rotation status" or "pika, create a PSK named iot-device-01".
  • Users & tokens: "pikachu, list all admin users" or "pika, create an API token for user alice valid for 30 days".
  • CA health: "pikachu, check the CA and CRL status" or "show me the dashboard stats".
  • Filtering & sorting: "pika, how can I filter certificates?" — the AI will call list_filter_capabilities and show you all options.
pki-mcp {{ mcp_server_version }} {{ skill_name }} {{ skill_version }} After installing, ask your AI: "call pki_list_versions" to verify.
Prerequisites
  • Python 3.10+ — optional: the install script detects Python automatically. If none is found it downloads a portable CPython (~30 MB) into pki_mcp\.python\ (repo-local, no system install, no admin required).
  • A PKI API token — go to Account → API Tokens (use an admin-role account for full tool access)
  • PowerShell 5.1+ (Windows built-in)
  • Internet access for the first run (pip + optional portable Python download)
Isolated venv: The install script creates a dedicated venv at pki_mcp\.venv\ — separate from the CA server's .venv. It contains only the MCP dependencies (mcp, httpx, pydantic), mirroring the server\.venv pattern used in the RAD agent toolkit.
HTTP mode: The MCP server does not store any PKI token. Each client passes their own personal token via X-PKI-Token on every request — this is how the PKI server attributes actions to the right user in the audit log.

GitHub Copilot — VS Code

Installs the MCP server entry into %APPDATA%\Code\User\mcp.json and copies the rad-pki-operations skill to ~\.copilot\skills\.

Step 1 — Bootstrap the MCP server (once per machine)

Skip if you already have pki_mcp installed from a previous setup.

PowerShell -ExecutionPolicy Bypass -File scripts\install\mcp_server\install-stdio-mcp-server.ps1
Step 2 — Install MCP + skill for VS Code
PowerShell -ExecutionPolicy Bypass -File scripts\install\skills_and_mcp\install-copilot-vscode.ps1
After install:
  1. Reload VS Code window (Ctrl+Shift+P → Developer: Reload Window)
  2. Accept the MCP trust dialog for pki-mcp
  3. Switch Copilot Chat to Agent mode
  4. Try: "pika, show me the dashboard stats"

HTTP Server — shared multi-client mode

Run a single pki-mcp HTTP server that multiple clients connect to by URL. No local Python needed per client.

Two-header authentication:
Authorization: Bearer <mcp-token> — shared server access token (set at install time)
X-PKI-Token: <personal-pki-token> — each client's own PKI API token; identifies them in the audit log
Option A — Windows (interactive, foreground)
PowerShell -ExecutionPolicy Bypass -File scripts\install\mcp_server\install-http-mcp-server.ps1

Prompts for: PKI CA URL • bind host/port • TLS mode • RW + RO Bearer tokens (auto-generated if blank). Config saved to .mcp-http.env.

Option B — Linux (systemd service, auto-start on boot)
sudo bash scripts/install/mcp_server/install-mcp-service.sh

Same interactive prompts across 3 sections. Installs to /etc/systemd/system/pki-mcp.service. Manages service with systemctl.

Wire each client to the running server

Each user runs this with their own PKI API token (prompted interactively):

# VS Code
PowerShell -ExecutionPolicy Bypass -File scripts\install\skills_and_mcp\install-copilot-vscode.ps1 `
    -Http -Url https://{{ server_dns_name }}:{{ https_port }}/mcp -Token <mcp-bearer-token>

# JetBrains
PowerShell -ExecutionPolicy Bypass -File scripts\install\skills_and_mcp\install-copilot-intellij.ps1 `
    -Http -Url https://{{ server_dns_name }}:{{ https_port }}/mcp -Token <mcp-bearer-token>

The installer will prompt for X-PKI-Token (your personal PKI API token from Account → API Tokens).

Resulting mcp.json entry
{
  "pki-mcp": {
    "type": "http",
    "url": "https://{{ server_dns_name }}:{{ https_port }}/mcp",
    "headers": {
      "Authorization": "Bearer <shared-mcp-token>",
      "X-PKI-Token":   "<your-personal-pki-api-token>"
    }
  }
}

Troubleshooting
SymptomFix
ModuleNotFoundError: pki_mcpRe-run install-stdio-mcp-server.ps1
401 X-PKI-Token header is requiredAdd X-PKI-Token: <your-pki-token> to your client's mcp.json headers
401 UnauthorizedCheck Authorization: Bearer <mcp-token> is set correctly in your client headers
403 [ADMIN]Your PKI token belongs to a non-admin user; create one at Account → API Tokens with an admin account
Connection errors on tool callsCheck the CA server is running at the configured PKI_BASE_URL; check firewall on the MCP port
TLS / SSL errorsSet PKI_VERIFY_SSL=false for self-signed CA certs, or provide a CA bundle path
Skill not loadingReload VS Code window; verify ~\.copilot\skills\rad-pki-operations\SKILL.md exists
pki-mcp missing from /mcp list (JetBrains)Re-run install-copilot-intellij.ps1
Skill/server version drift warningRe-run the install script then reload VS Code
Linux service: SELinux exec deniedsudo chcon -R -t bin_t pki_mcp/.venv/bin then sudo systemctl restart pki-mcp
Linux service: port < 1024 permission deniedRe-run install-mcp-service.sh — unit already sets AmbientCapabilities=CAP_NET_BIND_SERVICE
