PKISquire CA Server Paths Reference

Detailed behavior for current server paths: what each endpoint does, access level, and important request/response notes.

Source-derived from: app.py, users.py, events.py, x509_keys.py, x509_profiles.py, x509_requests.py, scep.py. Updated: 2026-02-27.

Legend for Access: Public, Login, Admin, Owner/Admin, Enterprise-gated.

Core App Paths

X.509 Keys Paths

PathMethodsAccessWhat It DoesKey Inputs / Outputs
/generateGET, POSTLoginGenerates key pair (RSA/EC/PQC).Form: key_name, type-specific params. PQC requires enterprise + provider.
/keysGETLoginLists keys with owner scoping and support status.Admin sees all; user sees own.
/keys/stateGETLoginPolling state endpoint.Output: JSON {count, max_id}.
/keys/<int:key_id>GETOwner/AdminShows key detail and derived formats (PKCS#1/SEC1/RFC4716 where applicable).Output: HTML view.
/keys/<int:key_id>/downloadGETOwner/AdminDownloads private key PEM.Output: PEM attachment.
/keys/<int:key_id>/deletePOSTOwner/AdminDeletes key record.Output: redirect to /keys.
/api/keys/<name>/privateGETEnterprise token over HTTPS or TRUSTED_HTTPS mTLSReturns private key PEM by key name.Requires API token. Also works on trusted listener with client cert. User token sees own keys only; admin token may access any key.
/api/keys/<name>/publicGETEnterprise token over HTTPS or TRUSTED_HTTPS mTLSReturns public key PEM by key name.Requires API token. Also works on trusted listener with client cert. User token sees own keys only; admin token may access any key.
