PKISquire CA - Repository Overview

This repository contains a Flask-based PKI CA server used for certificate lifecycle management: issuance, revocation, CRL publication, and validation. It also includes enrollment protocols (SCEP/EST), OCSP endpoints, user/admin workflows, and optional HashiCorp Vault key isolation.

  • Main app: app.py
  • Core modules: ca.py, vault_client.py, x509_*.py, users.py, events.py
  • Templates: html_templates/
  • Static assets: static/
  • Config: config.ini with detailed docs in README_CONFIG.md
  • Scripts: scripts/ (migrations, server helpers, Vault helpers)
  • Tests: tests/ (protocol scripts), tests_repo/ (pytest UI/API flows)

Page intent: quick architecture + endpoint map for contributors.
